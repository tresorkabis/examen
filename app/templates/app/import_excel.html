Format de fichier attendu
{% if type_active == 'etudiants' %}

Vous pouvez importer les étudiants de 2 manières :

Option A : Tableau standard
NomsN° ÉtudiantEmailPromotion
KABISAYI TRESORL3INFO-001tresor.kabisayi@etu.univ.cdL3 INFO A

Le modèle possède un seul champ texte noms : indiquez le nom et le prénom dans une seule colonne (ex. KABISAYI TRESOR). Le matricule est généré automatiquement quand celui-ci est omis.

Option B : Grille de délibération LMD

Fichier avec colonne 1 = N° d'ordre, colonne 2 = NOM POSTNOM PRÉNOM (nom de la feuille = promotion).

{% elif type_active == 'enseignants' %}

Format recommandé pour l'importation des enseignants :

NomsEmail
BABANEMI Jeanj.babanemi@example.com

L'email sera généré automatiquement s'il n'est pas renseigné.

{% elif type_active == 'cours' %}

Format recommandé pour l'importation des cours :

CoursPromotionEnseignantCoefficient
Programmation WebL3 INFO ABABANEMI Jean2
{% else %}

Fichier grille de délibération LMD d'une promotion :

  • ligne UNITES D'ENSEIGNEMENT : les UE, la ligne suivante leurs crédits ;
  • colonnes de synthèse : crédits validés, total pondéré, moyenne, décision, mention ;
  • une ligne par étudiant : N° d'ordre en colonne A, nom en colonne B, puis les notes /20.

Les notes, les crédits et la délibération sont recopiés tels quels. Les étudiants sont reconnus par leur matricule généré à partir du N° d'ordre.

{% endif %}
